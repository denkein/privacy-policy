3. Какие данные могут обрабатываться

Приложения могут обрабатывать техническую информацию, необходимую для их работы, улучшения качества сервиса и обработки встроенных покупок.

  • технические данные устройства и системы;
  • диагностическая информация об ошибках и сбоях;
  • данные, связанные со встроенными покупками, предоставляемые магазином приложений;
  • данные, связанные с проверкой доступности обновлений приложения;
  • внутренние данные приложения, связанные с прогрессом пользователя, статистикой, серией дней, достижениями, избранным и настройками.

4. Для чего используются данные

  • для корректной работы приложений;
  • для сохранения пользовательского прогресса, настроек и статистики;
  • для обработки встроенных покупок и восстановления доступа к платным функциям;
  • для проверки доступности обновлений приложения;
  • для исправления ошибок и улучшения стабильности приложений.

5. Встроенные покупки

В приложениях могут быть доступны встроенные покупки. Обработка платежей выполняется через платёжные сервисы магазина приложений, например AppGallery, RuStore или другой магазин, из которого установлено приложение.

Разработчик не получает и не хранит данные банковских карт пользователя.

Часть данных может обрабатываться сторонними платформами, если это необходимо для работы приложений, встроенных покупок, восстановления покупок, проверки обновлений, публикации или технической диагностики. К таким платформам могут относиться магазины приложений и их платёжные сервисы.

Мы не продаём персональные данные пользователей третьим лицам.
